### 背景

假设 App 发送：

```http
GET /asset/list
Authorization: Bearer xxx
```

请求到达服务器：

```text
手机 → 互联网 → Nginx → Spring Boot → Controller → Service → Repository → MySQL → 返回
```

### 问题 1

`GET /asset/list` 进入 Spring Boot 后，**它是怎么找到 `AssetController` 的？**

也就是为什么一个 HTTP 请求最后能执行到：

```java
// Controller/AssetController.java:24
@GetMapping("/list")
public List<Asset> list() {
    return assetService.list();
}
```
